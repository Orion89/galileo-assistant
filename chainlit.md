# 👨‍🚀 Bienvenido a Galileo

**Galileo** es un asistente inteligente basado en la API de Assistants de OpenAI, diseñado para analizar, optimizar y reforzar **decks de inversión de startups** que buscan financiamiento de Corporate Venture Capital (CVC).

Con un enfoque profesional y estructurado, Galileo evalúa:

- 📖 **Claridad de la narrativa**
- 📈 **Oportunidad de mercado y tracción**
- 💰 **Modelo financiero y métricas clave**
- 🎯 **Alineación estratégica con el CVC**
- 🧠 **Riesgos, fortalezas y oportunidades**

El objetivo es maximizar las probabilidades de éxito frente a comités de inversión, mejorando la calidad y solidez de cada propuesta.

---

## 🚀 ¿Cómo usar Galileo?

1. **Escribe tu consulta en la caja inferior.**  
   Ejemplos:
   - “¿Cómo evalúas esta sección del modelo de negocio?”
   - “¿Qué falta para que este deck sea convincente para un CVC?”
   - “¿Puedes mostrarme las fuentes que estás utilizando?”

2. **Espera mientras Galileo analiza...**  
   Verás una animación de “pensando...” mientras procesa tu input.

3. **Recibe un feedback claro, preciso y accionable.**
